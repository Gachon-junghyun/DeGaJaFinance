# SITES — 브라우저 함정 원장

> `site_map.json` 이 **"어디로 가나"** 라면 여기는 **"거기서 뭐에 걸렸나"** 다.
> 나가기 전에 그 사이트가 여기 있나 훑어라 — **같은 벽에 두 번 박지 않는 게 이 파일의 존재 이유다.**
> 새로 알아낸 함정은 **그 턴에** 여기 한 줄 + `site_map.json` 을 같이 고친다. 안 고치면 다음 런이 또 낸다.

---

## 0. 나가기 전 4줄 체크

1. **지도부터.** `python -X utf8 -m module_webctl find <검색어>` → `access` 와 `prefer` 를 본다.
   `api` 면 브라우저를 띄우지 마라 — 이 리포가 이미 그 기능을 소유하고 있다(P1).
2. **포트를 정한다.** 포트 = 프로필 = **로그인 계정**. `up --site <키>` 로 점유자부터 확인한다.
3. **새 탭에서만 움직인다.** `tabs` 로 남의 탭(신청서·결제·로그인)이 있나 먼저 보고, `newtab` 으로 시작한다.
4. **조회가 기본값.** 쓰기는 `--allow-write`, 되돌릴 수 없는 버튼은 **사람 확인 뒤 다음 실행에서**.

## 1. 이 리포에서 실측된 함정

### ① `--match` 를 서브커맨드 **앞**에 두면 무시됐다 (2026-08-14, 집행 안전 직결)
`python -m module_webctl --match timefolio eval --js ...` 가 조용히 **탭 0**(실측: `antimetal.com`)에
붙었다. argparse 의 parents 패턴에서 서브파서 기본값이 상위 값을 덮어쓰기 때문. ARMED 상태와 겹치면
남의 화면에 명령을 쏘는 것이다.
**수정됨(2026-08-29)**: `__main__._strip_conn` 이 파싱 전에 연결 플래그를 위치와 무관하게 걷어낸다 —
앞·뒤 어디에 둬도 같다. 근거: `llm_outputs/2026-08-14/timefolio/CLOSE_CHECK.md`.

### ② 9222 를 **다른 프로필의 크롬**이 점유한다 (2026-08-07·19·20·21·27·28, 6회 이상 재발)
`start_timefolio_chrome.bat` 은 "9222 already listening → skip" 이라 **점유자가 누구인지 안 본다.**
살아 있는 포트에 붙긴 붙는데 원하는 세션이 없다 — 증상은 "타임폴리오 탭이 없다"로 나타난다.
**대응**: `python -X utf8 -m module_webctl up --site timefolio_contest` — 후보 포트를 훑어 **탭 목록으로
점유자를 밝히고**, 원하는 세션이 없으면 빈 포트에 전용 프로필로 띄운다. 결과의 `scanned` 가 누가
어디 있는지 그대로 보여준다.
⚠ **그 프로필을 쓰는 크롬이 이미 떠 있으면 디버그 포트는 안 열린다**(크롬 제약) — `action:"blocked"` +
"그 창을 닫아라" 힌트가 그 경우다.

### ③ `TIMEFOLIO_CDP_PORT` 를 CLI 가 안 읽었다 (2026-08-28)
환경변수로 9223 우회를 걸어놓고도 CLI 는 9222 로 갔다. 세팅한 사람은 먹는다고 믿는다 — 그 침묵이 제일 비싸다.
**수정됨(2026-08-29)**: `--port` > `DEGAJA_CDP_PORT` > `TIMEFOLIO_CDP_PORT` > 9222 순으로 해석한다.

### ④ `WinError 10061` 은 고장이 아니라 "크롬이 없다"
그 포트에 크롬이 없을 뿐이다. 모듈을 의심하기 전에 `up` 을 먼저 돌려라(2026-08-24·25 실측, bat 자가기동으로 복구).

### ⑤ 크롬 111+ 는 새 탭을 `PUT /json/new` 로만 연다
`GET` 은 405 를 낸다. `CDPClient.new_tab` 이 PUT→GET 순으로 시도한다. 2026-08-26 에는 이걸 몰라
CDP 를 손으로 쳤다.

## 2. 사이트별

### DART (`dart`)
- 데이터는 전부 익명 접근된다. **로그인 세션을 만들지 마라**(My공시 알림용일 뿐).
- 목록·분류는 `module_disclosure`(OpenDART) 가 소유한다. 브라우저는 **원문 뷰어**(`report/viewer.do`)
  처럼 API 가 안 주는 것만. 뷰어는 `rcpNo`+`dcmNo` 조합이라 목록에서 받은 값을 그대로 써야 한다.
- 검색 폼: `#textCrpNm`(회사명, autocomplete). 결과 표가 뜰 때까지는
  `--until "document.querySelectorAll('table tr').length>2"` 로 기다린다(`sleep` 금지).

### 관세청 CTS (`customs_trade`)
- **SPA 라 URL 이 안 바뀐다.** 메뉴 이동은 `ets_f_prccMenuLoad(...)` 를 `eval` 로 부른다.
- 함정 셋: **숨은 패널의 동명 버튼**(같은 텍스트가 여러 개 — 셀렉터를 좁혀라) · **조회기간 5년 제한** ·
  **`alert` 이 뜨면 렌더러가 잠긴다**(그 상태에서 다음 eval 이 응답 없음으로 보인다).

### 타임폴리오 (`timefolio_contest`)
- 조회·주문 전부 `module_timefolio` 가 소유한다. 이 층에서 DOM 을 직접 치지 마라.
- `.env` 의 `TIMEFOLIO_EXECUTE=1` 이 살아 있다 — `--execute` 하나로 제출된다. **이중 게이트가 아니다.**
- 스크린샷에 계좌 잔고가 찍힌다. 커밋·공유 금지.

### Seeking Alpha / 유료 리서치
- 목록 **대량 수집 금지**(약관). 필요한 글 몇 편만. 코퍼스 적재는 card-factory 의 증분 ingest 가 소유.

## 3. 후퇴 신호 — 이게 뜨면 그 사이트는 그날 그만 두드린다

| 신호 | 대응 |
|---|---|
| **캡차 / 보안확인** | **즉시 중단.** 재시도·우회 금지. 공식 API 나 이미 있는 모듈로 갈아탄다 |
| 429 / "rate limit" / 200 인데 결과가 빈 정적 페이지 | 중단하고 사람에게 보고 |
| 로그인 벽 | 사람을 부른다. **자동 로그인 재시도 금지** — 계정 잠기는 게 답 못 찾는 것보다 훨씬 비싸다 |

## 4. 클릭이 조용히 씹힐 때

`probe --sel <css>` 가 원인을 갈라준다 — 증상은 셋 다 "클릭이 안 먹는다"인데 대응이 전혀 다르다.

| 진단 | 뜻 | 대응 |
|---|---|---|
| `가려져 있다 ← 'DIV.xxx' 가 덮음` | 모달·오버레이가 위에 있다 | 그걸 먼저 닫는다 |
| `크기가 0인 요소다` | 숨은 요소를 잡았다 | 셀렉터가 틀렸다 |
| `뷰포트 밖이다` | sticky 헤더/스크롤 컨테이너 | 스크롤 컨테이너 안에서 다시 잡는다 |

그래도 이상하면 **DOM 을 20번 더듬지 말고 한 장 찍어라** — `shot --full`. 텍스트로는 안 보이는
겹침이 그림에는 보인다.
