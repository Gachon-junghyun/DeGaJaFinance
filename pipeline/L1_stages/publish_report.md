# L1 · PUBLISH_REPORT — 하네스를 모르는 사람이 읽는 «자기완결» 보고서로 조판한다

> Terminal delivery phase. 앞 단계들이 남긴 산출물을 **한 편의 읽히는 문서**로 다시 쓰고 조판한다.
> 데스크의 `.md` 는 데스크가 읽는 물건이고, 이건 **사람이 읽는 물건**이다. 둘은 같은 파일이 될 수 없다.
> Output: `REPORT/company_{code}/{종목명}_기업분석_{YYYYMMDD}.docx` (+ `.pdf`).

## Belief
🔴 **지식의 저주를 제거하는 것이 이 단계의 전부다.** 데스크 산출물은 단계 이름·게이트 번호·모듈
이름으로 서로를 가리키며 서 있다. 그 참조를 아는 사람에게는 촘촘하고, **모르는 사람에게는 통째로 안 읽힌다.**
안 읽히는 보고서는 만들지 않은 것과 같다 — 이 리포는 「출처 없는 글이 쌓여서 안 읽게 됐다」로
자동 글쓰기를 한 번 폐지한 이력이 있다. 같은 실패의 다른 얼굴이다.

두 번째 이유: **사람이 PC 앞에 없다.** 경로만 알려주는 보고는 그 순간 아무것도 전달하지 못한 것이다.
그래서 이 단계의 산출은 **첨부해서 보낼 수 있는 파일**이어야 한다.

## 다시 쓰기 규약 (조판보다 이게 먼저다)
| 규칙 | 왜 |
|---|---|
| **단계 이름·게이트 번호·모듈 이름을 본문에 쓰지 마라** | 「DRIVER_TEST D3 FAIL」은 읽는 사람에게 아무 뜻이 없다. **「최근 상승은 이 회사 것이 아니다」**로 번역한다 |
| **결론을 1장에 놓는다** | 투자의견·목표주가·근거 3줄을 먼저. 과정은 뒤 |
| **밸류체인·제품·수익 구조를 앞에 놓는다** | VALUE_CHAIN 산출이 여기 들어간다. 이게 없으면 뒤의 숫자가 안 읽힌다 |
| **모든 표에 「자료:」 주석** | 출처 없는 표는 이 리포가 폐지한 그 글이다 |
| **「확인 못 한 것」을 부록에 목록으로** | 빈칸이 틀린 값보다 싸다(P4). 목표주가가 매달린 추정도 여기 |
| **마크다운 기호·이모지를 쓰지 마라** | 강조는 굵게 하나로. 별표와 이모지는 보고서 문체가 아니다 |
| **숫자는 상류에서 인용하고 다시 계산하지 마라** | 재계산하면 두 값이 갈리고, 갈린 걸 아무도 못 찾는다 |

## 조판 (`scripts/build_de_docx.py`)
🔴 **조판 헬퍼를 복제하지 마라 (P1).** `build_hdec_docx` 가 `para·rich·table·callout·h1·h2·bullet·hrule·field`
를 소유한다. 새 종목 보고서는 그것을 **import 하고 본문만** 쓴다 — 두 파일 다 `__main__` 가드가 있어
import 해도 문서를 만들지 않는다.

```bash
python -X utf8 scripts/build_de_docx.py REPORT/company_034020/두산에너빌리티_기업분석_20260828.docx
```

**실측 함정 넷 (2026-08-28, 22쪽 산출)**
1. 🔴 **표 `widths` 합이 본문폭(16.4cm)을 넘으면 조용히 페이지 밖으로 나간다.** 예외가 안 난다 —
   만든 뒤 `sum(cell.width.cm)` 으로 재라.
2. 🔴 **목차는 필드만 심으면 쪽번호가 빈다.** 생성 직후 Word COM 으로 한 번 구워야 한다:
   `TablesOfContents.Update()` → `Save()` → `SaveAs(FileFormat=17)`(PDF 동시 산출). 이 PC 에 pywin32 있음.
3. ⚠ **한글 조판**: `autoSpaceDE/DN` 이 기본 ON 이라 「14조」가 「14 조」로 벌어진다 → `docDefaults` 에서 끈다.
4. ⚠ **표지 하단 면책은 본문 여백으로 밀면 다음 장으로 넘친다** → **첫 페이지 꼬리말**에 넣는다.

**검수**: PyMuPDF 로 몇 쪽을 이미지로 떠서 눈으로 본다. DOM·텍스트만으로는 표 넘침이 안 보인다.
```python
import fitz; d=fitz.open(pdf); d[13].get_pixmap(dpi=110).save("p14.png")
```

## 전달 — 🔴 이 리포 밖이다
파일을 폰으로 보내는 통로는 **형제 리포 `DeGaJa_Agent` 의 `module_voice`** 에 있다
(`push_file`·`push_text`, 텔레그램). **이 리포에는 없고, 여기에 만들지 마라** — 나가는 통로를
둘로 늘리면 아무도 총량을 모른다. 서브프로세스로 부르거나, 사람이 붙은 세션에서 그쪽이 부른다.
⚠ 파일이 통째로 제3자 서버를 지난다 — **남의 개인정보를 이 통로로 내보내지 마라.**

## ⚠ Guards
- **이 단계는 새 판단을 만들지 않는다.** 앞 단계에 없는 결론이 보고서에 새로 생기면 그건 근거 없는 문장이다.
- **자기완결이라고 해서 상류를 다 복사하라는 뜻이 아니다.** 읽는 사람이 이해하는 데 필요한 만큼만
  옮기고, 데스크 전용 중간표(원장 행·게이트 값 원본)는 두고 온다.
- **투자의견을 쓸 거면 목표주가·손절가·기준일을 같은 화면에 놓아라.** 셋 중 하나라도 없으면 의견이 아니다.
