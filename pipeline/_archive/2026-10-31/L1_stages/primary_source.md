# L1 · PRIMARY_SOURCE — 요약이 아니라 «원문»을 뜬다 (브라우저·PDF)

> Phase 1.5. 결정론 팩이 채우지 못하는 세 축 — **컨센서스 추이 · 회사 IR 자료 · 공시 본문** — 을
> 실제 페이지에 들어가서 뜬다. 이 단계는 해석하지 않는다. **본문을 손에 넣는 것이 산출물이다.**
> Output: `SOURCES.md` (뜬 원문 + 접속 시각 + 못 뜬 것).

## Belief
🔴 **요약으로 읽은 것은 「확인함」이 아니다.** 검색 요약과 API 는 **표에 든 값(날짜·금액·번호)은 넘기고
문장으로 된 제약과 시계열은 버린다.** 그런데 남은 쪽이 빈 데가 없어 보여서 「다 읽었다」로 착각된다.
그 착각이 만드는 오류는 조용하고, 조용하기 때문에 하류가 전부 그 위에 쌓인다.

**세 축은 결정론 팩에 «구조적으로» 없다.** 없는 걸 모르고 지나가는 게 이 단계가 막는 실패다:

| 축 | 왜 팩에 없나 | 없으면 무슨 판단이 불가능해지나 |
|---|---|---|
| **컨센서스 추이** | DART·KIS 는 «지금 얼마 버나»만 준다. 시장의 «기대»는 애초에 공시 대상이 아니다 | 「이익이 올린 건가 배수가 올린 건가」 — 현재 배수만으로는 답이 안 나온다 |
| **부문 수주·수주잔고·가이던스** | 사업보고서에 부문별 **매출**은 있어도 부문 **영업이익·수주잔고·연간 계획**이 없다 | 수주산업의 미래 매출 전체. 잔고를 모르면 성장 논거가 통째로 빈다 |
| **공시 본문의 «문장»** | 목록 API 는 제목·금액만 준다 | 「우선협상대상자로 선정됐으나 금액 미정, 재공시 2026-11-06」 같은 **날짜 박힌 촉매** |

## 어디로 가나 (KR)

|---|---|---|

**브라우저**: 이 리포는 [module_webctl](../../MODULE_MAP.md)(CDP 9222 — `tabs·eval·text·wait·click·shot`)를 쓴다.
실측한 경로는 형제 리포 `DeGaJa_Agent` 의 `module_browser fast run` 으로, **스텝 배열을 한 번에 부어**
왕복을 없앤다(`goto(url, until)` · `eval` · `links` · `text`). ⚠ **그쪽을 쓸 때도 import 하지 말고
서브프로세스로만 불러라** — 두 리포는 런타임이 붙어 있지 않다.

## ⚠ 실측 함정 넷 (2026-08-28, 034020)
1. 🔴 **탭 지정은 id 가 아니라 «제목·URL 부분문자열»이다.** 새 탭을 만들 때 받은 id 를 `--tab` 에 넣으면
   **「그런 탭이 없다」로 죽는다.** 목적지 URL 로 탭을 열고 도메인 조각(`wisereport`·`dart`)으로 맞춰라.
   `about:blank` 로 열면 다른 빈 탭과 구분이 안 된다.
2. 🔴 **DART `dsaf001/main.do` 의 `innerText` 는 목차·버튼뿐이다.** 「본문이 비었다」로 오진한다 —
   iframe `src` 를 먼저 뽑아라. (모듈이 `dsaf001` 을 긁어 **네비게이션 텍스트를 본문으로 돌려준** 전례가 있다.)
3. 🔴 **IR PDF 는 `Read` 툴로 안 열린다**(`pdftoppm` 없음). **PyMuPDF(`fitz`)로 텍스트를 뽑아라** — 설치돼 있다.
4. ⚠ **IR PDF 는 발표자료라 각주·라벨이 도형 텍스트**여서 앞글자가 잘려 나온다(「대형원전」→「형원전」).
   **표와 숫자는 멀쩡하다.** 숫자만 믿고 문장은 다시 확인해라.

## ⚠ 후퇴 신호
캡차·보안확인·429·로그인 벽을 만나면 **그날 그 소스는 그만 두드린다.** 우회·재시도 금지.
공식 API 로 갈아타거나 「미확보」로 남긴다 — 계정이 잠기는 게 값을 못 찾는 것보다 비싸다.

## 🚨 U7 · `module_webctl` — `--match` 전에 **반드시 `newtab <목적지 URL>`**

이미 KR 절에 적혀 있으나 **US 경로에서도 그대로 밟았다**(2026-09-03).
`run`/`text` 에 `--match developer.nvidia` 를 바로 주면 **`CDPError: 매칭 타깃 없음`** 으로 죽는다 —
그 도메인의 탭이 아직 없기 때문이다. 순서는 **`newtab <URL>` → 잠깐 대기 → `text --match <도메인조각>`**.
